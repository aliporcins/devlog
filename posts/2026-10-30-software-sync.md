## 这次同步了什么

只同步最新版，不同步作废版、销售版与收费版直链。图书馆与博客刷机指南保持一致，下载按钮下方按惯例显示地址原文。

- **大金传感器固件 2.2.35**：新入馆，**首次走 GitHub 永久链**。直接 supersede 2.2.33 与 2.2.34：A1 PM 指数标签带分界参数（PM2.5 以 35、PM10 以 50 为界，此前 PM10 36–50 会被错标超标）、B1 通知扩到 5 项（各自开关与阈值）、A3 MQTT Home Assistant 发现消息加温湿度（联调待飞牛开机）。
- 文件 firmware-slim-2235.bin，1,819,344 字节，SHA256 `d39df82c9fa47bac6331db61345e990218b40a157c8d292f89607b42b630b34b`。私有仓 Release，需 GitHub 登录态下载。注意两点：设备现跑 2.2.27、OTA 仍坏，2.2.35 须串口刷机才生效（串口线到货后只刷这一版）；2.2.33 的 Muse 临时直链 **2026-10-31 09:44 CST 过期**，已作废、不要再用。
- **PokePVE 1.1.1**：新入馆。深色柔和版，正式 Release。
- 文件 poke-pve-v1.1.1.zip，21,143 字节，SHA256 `d65f6e274c2be44df8543a50b0b39ac1b5c65e975ecc28363b835689a031a1f4`。私有仓 Release，需 GitHub 登录态下载；升级为解压覆盖同文件夹后在扩展页重新加载。
- **luci-totp r6**：新入馆。OpenWrt LuCI 登录 TOTP 二次验证插件（仅 25.x ucode 版 LuCI，24.10 及更早 Lua 版不适用）。r6 相对 r5 只有界面改版：二次验证页换深色高级样式（卡片、青色主题、圆角、大字验证码框），文案、表单字段与零外网请求全保留。
- 文件 luci-app-totp_0.1.0-r6_all.apk，40,274 字节，SHA256 `ff94f1a6ed4ffba54d1f40a9e1a4f51135abb29fea50a2d76d4cfd439ad0881c`。私有仓 Release，需 GitHub 登录态下载。注意：r5 是生产已装版；升 r6 时保持当前 LuCI 会话开着，升完用隐私窗口验新页面。r6 的 Muse 临时直链 **2026-11-01 08:21 CST 过期**，已被永久链取代。
- **博客刷机指南同步改到 2.2.35**：入口总汇里的大金刷机指南卡片与指南正文里的固件名、大小、SHA 与直链均已改到 2.2.35，2.2.33 与 2.2.34 已作废、不要刷旧版。
