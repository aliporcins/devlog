## 背景

昨天半夜把 Yu9191 的仓库（https://github.com/Yu9191）翻了一遍，35 个公开仓库，筛出五个最值得用的：decode_action、Script-Hub、tower（塔台）、Douyin_TikTok_Download_API、KuGou。weping 之前已经部署好了（见上一篇），这篇是剩下五个的落地记录。

先说结论：**两个已部署上线，三个只做了文档**——不是偷懒，是平台限制：塔台要 Mac＋Xcode 才能编，抖音下载 API 是 Python 服务上不了 Workers，酷狗 API 要抓包拿 Token 才能用。付费墙解锁类（wpyx、JTSP）和验证码工具（ddddocr-fastapi）按规矩没碰。

## 1. decode_action：JS/Python 自动解密 ✅ 已部署

**是什么**：GitHub Action，扔一个混淆过的 JS 或 Python 文件进去，60 秒左右自动解密，输出可读的代码。支持 sojson v6/v7、javascript-obfuscator、awsc、jjencode、zlib/bz2/lzma 等。

**部署**：私有仓库 https://github.com/aliporcins/decode，工作流 `.github/workflows/decode.yml`，触发方式两种：

- 往 `main` 分支推 `input.js` / `input.py`，自动跑；
- Actions 页面点 Run workflow 手动跑（workflow_dispatch）。

**实测**：已跑通。第一次跑失败了——上游依赖 `isolated-vm` 在 GitHub 默认的 Node 22 环境下编不过（V8 API 变了）；修法是工作流里锁定 Node 20，重跑后成功。测试输入是自己写的小样本再混淆的，解密后 `output.js` / `output.py` 都已验证可读，和原文一致。

**怎么用**：

1. 把要解密的文件命名为 `input.js` 或 `input.py`，推到仓库 `main` 分支（或直接在网页上上传覆盖）；
2. 等一分钟左右，Actions 跑完自动把 `output.js` / `output.py` 提交回仓库；
3. 在仓库里直接看 `output.js` / `output.py`。

注意：解密结果是提交回仓库的，仓库是私有的，只有登录 GitHub 才能看。

## 2. Script-Hub：代理工具重写与规则集转换器 ✅ 已部署

**是什么**：面向 iOS 代理工具（Quantumult X / Loon / Surge / Stash / Egern / Shadowrocket）的转换器：QX 重写、Surge 模块、Loon 插件、各类规则集互相转换，还能做 QX 脚本→Surge 脚本兼容转换、一键导入各 App。

**部署**：Cloudflare Pages 静态站，项目名 `script-hub`，已上线：

- https://script-hub-5vv.pages.dev/

部署方式是 `pnpm export_html` 导出静态页（`dist/index.html`，约 233 KB），再用 wrangler 推上 Pages。导出时顺手修了上游一个小毛病：生成的文件缺 `<!DOCTYPE html>`，构建后补上了。

**功能边界（重要）**：静态页只能做“粘贴本地文本→浏览器内转换”（页面里勾上“开启纯前端转换”）。粘贴远程 URL 生成转换链接、点开后真正取回结果，需要后端服务（`service.js`，Koa，9100 端口）或在代理 App 里装模块才能跑。完整能力走 Docker：

```bash
docker build -t script-hub .
docker run -d --name script-hub -p 9100:9100 -p 9101:9101 script-hub
```

起来后访问 http://127.0.0.1:9100/（Beta 版 9101）。

**域名小插曲**：本来想绑 script-hub.hench.cc.cd，Pages 的域名接口报 `.cc.cd` 是无效 TLD，加不上；试过先加 CNAME 再访问，结果 522——Pages 不认没在项目里注册过的域名。先用 pages.dev 的地址，域名以后再说。

## 3. tower（塔台）：iPhone 代理订阅管理 App 📝 仅文档

**是什么**：原生 SwiftUI iOS App，在 iPhone 本机管理代理订阅、自有节点与规则，生成各客户端配置。支持 SS、SSR、VMess、VLESS、Trojan、Hysteria、TUIC、WireGuard 等协议，一键导出到 Shadowrocket、Stash、Surge、Loon、QuanX、Clash、sing-box 等 11 个客户端。**它不建隧道、不接管流量**，只做订阅管理和配置生成。

隐私模型很干净：转换、规则匹配、地区查询全在本机完成，不经过第三方在线转换服务；订阅凭据默认只留设备。

**为什么只做了文档**：它是原生 iOS 应用，必须用 Mac＋Xcode 构建，Linux 沙箱里编不出来。最低 iOS 17，建议 Xcode 26+。

**怎么用（有 Mac 的话）**：

1. 克隆 https://github.com/Yu9191/tower；
2. 打开 `Tower.xcodeproj`，跑 `Tower` Scheme；
3. 真机安装需要 Apple 账号签名（`DEVELOPMENT_TEAM` 没写死在工程里，本地用 Xcode 覆盖）。

## 4. Douyin_TikTok_Download_API：短视频解析下载 API 📝 仅文档

**是什么**：抖音 / TikTok / Bilibili 异步解析＋无水印下载 API（Evil0ctal 原项目，Yu9191 的是 fork）。网页端批量解析（一次最多 30 条链接），REST API 覆盖视频解析、用户主页、直播流、评论、合辑等；配合 iOS 快捷指令能在应用内无水印下载。

**为什么只做了文档**：这是 Python 服务（FastAPI＋PyWebIO），只能跑在自己的 Linux 服务器或 Docker 里，**上不了 Cloudflare Workers**（Workers 没有 Python 运行时和常驻进程）。部署后还必须在浏览器里取已登录抖音账号的 Cookie 填进配置，否则接口不可用。

**本地运行（Docker，最简单）**：

```bash
docker pull evil0ctal/douyin_tiktok_download_api:latest
docker run -d --name douyin_tiktok_api -p 80:80 evil0ctal/douyin_tiktok_download_api
```

跑起来后 API 文档在 http://localhost/docs。注意两点：它走的是逆向后的 Web 端签名（X-Bogus / A_Bogus），平台一改版就可能失效；TikTok 视频直链直接访问会 403，必须走它自己的 `/api/download` 接口。

**对播放器的参考价值**：`crawlers/` 的分层值得借鉴——平台爬虫只负责“请求→取回→返回 dict”，API 层只负责“收参数→调爬虫→返回 JSON”，前端是薄薄一层。播放器要接短视频源时，可以照这个分层做一个本地解析服务：播放器只调 HTTP API，签名、Cookie、风控全收敛在服务端一处。

## 5. KuGou：酷狗音乐第三方 API 📝 仅文档

**是什么**：酷狗音乐的非官方第三方 API（Node.js 18+，Express，MIT 协议）：歌曲搜索、播放链接、歌词、音质信息。README 明确声明仅供学习交流，请勿用于商业用途。

**为什么只做了文档**：它要跑起来得先抓包拿 Token（TOKEN、MID、USERID、KG_RF、KG_DEVID 都要从酷狗客户端的请求里提取），而且约 1–2 天触发一次人机验证，暂无自动化解法。这东西适合在自己机器上跑着玩，不适合当作面向用户的正式音乐源。

**本地运行**：

```bash
git clone https://github.com/Yu9191/KuGou.git
cd KuGou
npm install
cp .env.example .env     # 填入抓包得到的 TOKEN、MID、USERID 等
npm start                # 默认端口 9191，访问 http://localhost:9191 看在线文档
```

核心端点：`GET /api/search?keyword=周杰伦`（搜歌）、`GET /api/v5url?hash=…&quality=high`（取播放地址，high/320/128 自动降级）、`GET /api/lyric?hash=…`（LRC 歌词）、`GET /api/audio_info?mixSongId=…`（全部可用音质）。也能当库 import 进 Node.js 项目直接调用。

**对播放器的参考价值**：搜索→取播放地址→取歌词→取音质，四步正好对应播放器音乐模块的数据链路；`v5url` 的 lite/full 两种输出和音质自动降级可以直接照搬。
