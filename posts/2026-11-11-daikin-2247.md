## 这次同步了什么

只同步最新版。大金 2.2.47：

- **新增 mDNS**：主机名 dj，浏览器打开 http://dj.local 就进后台，不用知道 IP；搬新房子换 WiFi 也一样，不用进路由器后台。
- **新增 Bark 推送 IP**：连上 WiFi 拿到新 IP 时推一条 Bark 通知（标题“大金已连接”），正文含内网地址与 http://dj.local；IP 不变不重复推。
- **原样保留**：2.2.46 的 panic 修复（状态灯任务栈）与 2.2.45 的室外空气修复（AQI）；HomeKit 配对不受影响。
- **文件**：firmware-slim-2247.bin，1,948,320 字节，SHA256 `7cbbb14ab37f8773e1a8a8910a93f60803986e292237aae34e931fd6b25b9e17`。私有仓 Release，需 GitHub 登录态下载。已验证：Release 已发布（非草稿）、资产 state=uploaded，大小与 SHA256 与本地构建产物逐字节一致。本版 1,948,320 字节，OTA 槽为 1,966,080 字节，网页 OTA 可直接升级；2026-11-11 08:55 已由网页后台 OTA 成功上机，08:56–08:57 复查 fw 2247、读数正常、HomeKit 配对未掉；VM 上 ping dj.local 解析到 192.168.2.220、curl http://dj.local/ 返回 200，Bark 推送 code 200。
