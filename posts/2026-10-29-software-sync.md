## 这次同步了什么

只同步最新版，不同步作废版、销售版与收费版直链。图书馆与博客刷机指南保持一致，下载按钮下方按惯例显示地址原文。

- **大金传感器固件 2.2.33**：新入馆。改动只有一处：综合指数 IAQ 与湿度卡片位置互换，综合指数在下方大卡片，湿度为小卡片与温度同排；CSS 与 JS 未动，卡片 ID 未变。
- 文件 firmware-slim-2233.bin，1,816,432 字节，SHA256 `fdb253b47000f9f30bbfdba986fd0923a0e30bcff8b54aa989687a25f24247a7`。注意两点：设备现跑 2.2.27、OTA 仍坏，2.2.33 须串口刷机才生效；馆内这条是临时直链，**2026-10-31 09:44 CST 过期**，过期后需发 Release 换永久链，不要谎称永久。
- **PokePVE 1.0.7**：新入馆。PVE 浏览器扩展，打开 PVE 登录页自动填账号密码与二次验证码（可选），只在用户自己配置的 PVE 地址上生效。
- 文件 poke-pve-v1.0.7.zip，18,737 字节，SHA256 `95496e2de733881dc92004b6cf188942f0bd51210ddff823a800022ab77db283`。私有仓 Release，需 GitHub 登录态下载；升级为解压覆盖同文件夹后在扩展页重新加载。
- **博客刷机指南同步改到 2.2.33**：入口总汇里的大金刷机指南卡片与指南正文里的固件名、大小、SHA 与直链均已改到 2.2.33，2.2.32 已作废、不要刷旧版。

## 核对过、已在馆、无需改的

- NOVX 免费版 1.13.43、筋斗小圣 1.6.1（IPA 与 APK）、IPAToolbox 1.1.14、AX3000T 固件 24.10.6（标准版 sysupgrade，59,792,186 字节）：馆内版本与实测文件一致，无落后。
- 开发记录的时间轴入口（NOVX、筋斗、IPAToolbox 的版本页链接）未变，仍在博客“开发记录”页。

## 故意没进馆的

- 大金 2.2.27 至 2.2.32：2.2.27 是现运行版但未单独入馆，2.2.32 已作废，中间版一律不同步，只同步最新 2.2.33。
- 大金销售版固件：含激活门控的闲鱼销售线，绝不公开分发，不进馆、不进博客。
- NOVX Pro：收费产品。馆内已有的 1.0.0 条目保持原样不动；测试版 1.0.1-test 只在 mini-pc 与 VM 上实测激活中，**不给安装包直链**，博客卡片如要出现也只能是介绍与购买指引，等另定。
- K2P B1 固件与 AX3000T 的 ubootmod 变体：前者无永久下载链，后者不是已交付的标准版，暂不进馆，等另定分发渠道。
