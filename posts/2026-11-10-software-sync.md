## 这次同步了什么

只同步最新版。NOVX Pro 正式版 1.0.2（上一正式版为 1.0.1）：

- **NOVX Pro 1.0.2**：以 1.0.50 测试树出的正式安装包，带版本信息与图标；含 1.0.42–1.0.50 全部测试批自 1.0.1 以来的累计改动。
- **本版的直接改动是播放器冷开场海报闪修复**：播放窗打开前先把海报图预加载好（缓存图直接用，未缓存等图到后再出窗），海报加淡入过渡，黑底→海报的一跳不再出现；3 秒放行门、首帧、兜底、看门狗逻辑一字未动。
- 文件 NOVX.Pro.Setup.1.0.2.exe，203,019,004 字节，SHA256 `476662c786efa32feb2c761f708a8351c95e73500d621b51b9868a81ac5cc3d0`。私有仓 Release，需 GitHub 登录态下载。已验证：Release 已发布（非草稿）、资产 state=uploaded，大小与 SHA256 与构建产物逐字节一致；VM 静默安装（/S，退出码 0）与系统自带卸载器卸载均通过，用户数据完整保留。安装包由仓库 CI 构建，tag 指向本次构建提交。

永久链：[NOVX.Pro.Setup.1.0.2.exe](https://github.com/aliporcins/nova-player/releases/download/v1.0.2/NOVX.Pro.Setup.1.0.2.exe)（GitHub Release，私有仓，需 GitHub 登录态下载）。

说明一点：1.0.2 修的是冷开场海报盖画面那一下；用户本机录像里“首帧出现后又加载一次才出画面”属另一环节，不在此版修复范围，仍在诊断中。
